# مینی پروژه های فرانت اند
در این ریپازیتوری مینی پروژه های فرانت اند به صورت اپ های جداگانه در یک پروژه React واحد قرار داده میشود.
هدف اصلی این مینی پروژه ها افزایش تسلط و یادگیری من در توسعه فرانت اند خواهد بود.

ابزار های مورد استفاده در این نمونه کار ها شامل:
- HTML, CSS, Java Script
- Tailwind CSS
- React.js
